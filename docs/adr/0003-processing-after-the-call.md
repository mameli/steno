# Processing after the call, guided by Personal notes

Unlike Granola, Steno does not transcribe live: it records and, at the stop, produces Transcript and Summary. Granola's value is recovered through Personal notes, which the user writes during the Meeting in the Meeting note in Obsidian and which guide the Summary. Live transcription would have needed streaming, a window of its own and real-time error handling, for a marginal benefit over a wait of a few minutes.
