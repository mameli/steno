# A single OpenAI-compatible adapter; external local LLM, integrated Whisper

Almost all candidate Providers (Mistral, Scaleway, OVHcloud, IONOS, Azure v1, Ollama, LM Studio, llama.cpp) expose OpenAI-compatible APIs for chat and transcription, so Takku has a single generic adapter configured through named Profiles instead of one client per Provider. The local LLM runs outside the app (llama.cpp/Ollama/LM Studio) so Takku does not manage model downloads and memory; local transcription is integrated instead (WhisperKit) because it is used in every Meeting and must work without other programs running.
